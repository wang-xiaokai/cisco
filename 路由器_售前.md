

# Catalyst 8000

## 1. Cisco 8000 Secure Router

### 1.1 许可区别

2.许可区别
（1）IPSec&HSEC license
HSEC许可不适用C8000 Secure路由器
A High Security license, also referred to as a HSEC or a HSECK9 license, is not applicable and is not required for Cisco 8000 Series Secure Routers.
https://www.cisco.com/c/en/us/td/docs/routers/cloud_edge/licensing/8000-series-secure-routers-licensing.html
（2）OS Essentials和Routing Advantage功能区别
OS Essentials是永久，Routing Advantage是订阅

默认强制机箱带的永久许可OS Essentials，只支持基础P2P IPSec，但最高限制在 Up to 250Mbps Crypto。高级VPN要用Routing Advantage。
Cisco OS Essentials and Routing Advantage Feature Set   许可对比
https://www.cisco.com/c/dam/m/en_us/products/software/wan-routing-licensing-feature-matrix.pdf

Routing Advantage订阅最低84个月售卖，支持DMVPN, GETVPN, FlexVPN, P2P IPSec。解除250Mbps限制，加密吞吐量不再被限制
Cisco Routing Advantage: This license offers advanced routing capabilities for a traditional routing deployment. This license has a 84-month subscription period, and can be used for a device in autonomous mode or SD-Routing mode.
https://www.cisco.com/c/en/us/td/docs/routers/cloud_edge/licensing/8000-series-secure-routers-licensing.html

If you use Cisco IOS XE 17.15.x, after the reload, the device starts with the routing-Advantage license and crypto throughput is unthrottled.
https://www.cisco.com/c/en/us/td/docs/routers/cloud_edge/licensing/8000-series-secure-routers-licensing.html

C8000 Secure路由器不再使用T1/T2/T3带宽层级
Elimination of bandwidth tiering: Licenses for the next-generation hardware will not be segmented by bandwidth tiers.
https://www.cisco.com/c/en/us/products/collateral/networking/software/next-generation-licensing-routing-wan-so.html

## 3.ISR4000路由器



ISR4000路由器从16.10.1开始只支持Smart License

Smart Licensing is optional for versions between 16.5.1 and 16.9.8. For physical devices with Cisco IOS® XE 16.10.1a up to Cisco IOS® XE 17.3.1 Smart Licensing is mandatory. From 17.3.2 and onwards, Smart Licensing Using Policy is mandatory. For virtual devices and other Cisco platforms check the release notes of the specific code.
